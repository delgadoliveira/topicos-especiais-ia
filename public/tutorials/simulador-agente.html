Para que serve este simulador? Ele permite aprender e testar a estrutura do agente sem misturar dois problemas ao mesmo tempo: fazer o sistema funcionar e avaliar a qualidade de um modelo de IA. Aqui você consegue conferir entrada, guardrails, formato da saída, passos executados e tratamento de erros. Como a resposta é previsível, uma mudança no resultado aponta para uma mudança no código. Ele não substitui uma IA real: não interpreta o pedido, não raciocina e não avalia se o plano de estudos é semanticamente bom.

def _mock_answer(messages):
    user = próxima_mensagem_do_usuario(messages)
    palavras = user.split()
    trecho = " ".join(palavras[:25])
    return "[MOCK · modo offline] Resposta simulada para: " + trecho
Este laboratório poderia usar uma API real? Sim, mas não chamando o provedor diretamente desta página. Em um site público, o token ficaria visível no navegador. A arquitetura segura é: navegador → backend controlado → API do modelo. Esse backend deve validar a entrada, limitar chamadas e tamanho da resposta, aplicar timeout, reutilizar cache e nunca devolver o token ao aluno. Nesta versão pública, mantemos somente o simulador para garantir acesso sem conta, custo ou coleta de dados. A comparação com Qwen é feita no portal local, em um checkpoint orientado pelo professor.
