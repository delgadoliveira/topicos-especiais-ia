A regra que protege a aula

Tudo deve funcionar com MOCK_LLM=1.

A API real nao e requisito para construir, testar ou apresentar.

Hoje nao precisamos de token, Git, deploy ou conta em nuvem.

Mapa de 7 passos

  1. Preparar a pasta e o ambiente
  2. Escolher uma tarefa pequena
  3. Definir uma saida verificavel
  4. Copiar o template
  5. Editar quatro campos
  6. Rodar o preflight
  7. Abrir o portal

Passo 1 — ambiente

py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python check_agent.py agents/example_resumidor.py

macOS/Linux: veja os comandos equivalentes no tutorial.

Passo 2 — uma tarefa pequena

Meu agente ajuda [pessoa] a [uma tarefa], recebendo [entrada] e devolvendo [saida verificavel].
Bom: transforma anotacoes em tres acoes.
Grande demais: ajuda em qualquer assunto.

Copy-Item agents\_template_agent.py agents\organizador-estudos.py

Slug: minusculo, sem espaco, sem acento, com hifen.

Cada aluno edita somente o proprio arquivo em agents/.

Prompt como contrato

Inclua
papel · formato · quantidade · limite
Evite
“seja otimo” · “faca tudo” · regras contraditorias
Se voce nao consegue conferir a saida, o agente ainda nao tem um bom contrato.

Passo 6 — preflight

python check_agent.py agents/organizador-estudos.py
1. carrega o arquivo
2. procura AGENT
3. valida slug e contrato
4. executa smoke test offline

Checkpoint 1: corrija a mensagem concreta; nao adivinhe.

Passo 7 — portal local

python app.py

Abra http://127.0.0.1:7860, selecione seu agente e envie o exemplo.
