🗺️ O produto: Portal Multi-Agente

Um site único onde cada aluno pluga seu próprio agente. O portal descobre, lista e conversa com cada um.
usuário → escolhe um agente no menu 🧠 ✂️ 🧮 ⚖️
[portal] descobre agents/*.py automaticamente
[portal] se um agente quebra, os outros seguem de pé
agente responde + mostra passos, fontes e latência
Você trabalha em um único arquivo: agents/<seu-slug>.py. O resto da infraestrutura já está pronto.

📜 Regras do jogo

🆓 100% open source e gratuito. Modelo aberto (Qwen) via Hugging Face, token grátis.
🎯 Um agente por aluno. Tarefa única, bem definida e verificável.
🤝 Contrato comum. Todo agente "fala a mesma língua" do portal.
🧪 Roda offline. Modo MOCK_LLM=1 para desenvolver sem rede.
🧹 Só o seu arquivo. Não mexa em portal/ nem no agente dos colegas.
🚀 Deploy no E6. Publica grátis no Hugging Face Spaces.

🤝 O contrato — a "língua comum"

A única regra: seu agente é um objeto com 4 metadados + um método run() que devolve um AgentResult.

from portal.base import AgentResult

class MeuAgente:
    slug = "meu-agente"      # id único, minúsculo, sem espaço
    name = "Meu Agente"      # nome amigável (aparece no menu)
    emoji = "🧠"              # um emoji para a UI
    description = "O que ele faz, em uma frase."

    def run(self, message, history):
        # message  -> str  (o que o usuário digitou)
        # history  -> lista de {"role", "content"} (turnos anteriores)
        return AgentResult(
            answer="a resposta ao usuário",   # obrigatório
            steps=["passo 1", "passo 2"],      # opcional (observabilidade)
            citations=["fonte A"],             # opcional (se usar RAG)
        )

AGENT = MeuAgente()          # o portal descobre o agente por esta variável
Sem herança obrigatória: basta ter esses atributos e o run(). Simples de propósito.

🏗️ Como o portal funciona por dentro

agents/ cada aluno cria <slug>.py com uma variável AGENT
⬇
registry.py importa cada arquivo, valida o contrato, ignora os quebrados
⬇
runner.py roda run() com timeout + captura de erro + log
⬇
app.py UI Gradio: menu de agentes + chat
🛡️ Tolerante a falhas: um agente com bug não derruba a turma. O erro aparece na tela.
🔌 Zero config: salvou o arquivo, o agente já aparece no portal.

💡 Passo 1 — Ideação: escolha um arquétipo

Não sabe o que fazer? Comece por um destes moldes e adapte ao seu domínio (área, hobby, trabalho).

📝 Transformador: resume, traduz, reescreve, formata (ex: resumo de artigo, e-mail formal → informal)
🔎 Explicador: explica um conceito no nível do usuário (ex: termo jurídico, erro de código)
🧮 Analisador: recebe dados e devolve um veredito (ex: revisa uma query SQL, avalia um currículo)
🛠️ Gerador: produz um artefato pronto (ex: mensagem de commit a partir de um diff, plano de estudo)
🧭 Tutor: guia o usuário por passos (ex: monta uma receita, corrige exercício)
📚 Consultor c/ fontes (RAG): responde citando um material que você forneceu

✂️ Passo 2 — Escopo em UMA frase

"Meu agente ajuda [usuário] a fazer [tarefa específica]
usando [entrada] e entregando [saída verificável]."
✅ Bom: "ajuda estudantes de SQL a corrigir uma query que dá erro usando a query + a mensagem de erro e entregando a query corrigida + a explicação."
❌ Vago: "um assistente que responde qualquer pergunta", "ajuda com produtividade", "um chatbot legal". Sem tarefa nem saída verificável.
Regra de ouro: se você não sabe como testar se a saída está certa, o escopo ainda está vago.

✂️ Passo 5 — Implemente run() (exemplo completo)

Um agente Resumidor real e funcional. Estude cada linha — é o molde do seu.

from portal.base import AgentResult
from portal import llm

class ResumidorAgent:
    slug = "resumidor"
    name = "Resumidor de Textos"
    emoji = "✂️"
    description = "Resume um texto longo em até 3 tópicos curtos."

    def run(self, message, history):
        steps = ["Recebi o texto", "Pedi um resumo em 3 tópicos"]
        resumo = llm.chat([
            {"role": "system",
             "content": "Você resume em português. Máx. 3 tópicos, cada um em '- '."},
            {"role": "user", "content": f"Resuma:\n\n{message}"},
        ], max_tokens=200)
        return AgentResult(answer=resumo, steps=steps)

AGENT = ResumidorAgent()
llm.chat() já cuida de token, retry, timeout e modo MOCK. Você só pensa no prompt e na tarefa.

🛠️ Opcional — Dando "ferramentas" ao agente

Precisa calcular, buscar ou consultar algo? Chame uma função Python normal dentro do run(). Simples assim.

import re
from portal.base import AgentResult
from portal import llm

def calcular(expr: str) -> str:               # "ferramenta" = função Python
    if not re.fullmatch(r"[0-9+\-*/(). ]+", expr):
        return "expressão inválida"
    return str(eval(expr))                      # ok: entrada já validada

class CalculadoraAgent:
    slug = "calc"; name = "Calculadora Explicada"; emoji = "🧮"
    description = "Resolve uma conta e explica o passo a passo."

    def run(self, message, history):
        conta = re.search(r"[0-9+\-*/(). ]+", message)
        resultado = calcular(conta.group()) if conta else "não achei uma conta"
        explicacao = llm.chat([
            {"role": "system", "content": "Explique a conta em 1 frase simples."},
            {"role": "user", "content": f"{message}\nResultado: {resultado}"},
        ], max_tokens=80)
        return AgentResult(answer=f"**{resultado}**\n\n{explicacao}",
                           steps=[f"calculei: {conta.group() if conta else '-'}"])

AGENT = CalculadoraAgent()

📚 Opcional — RAG mínimo (responder com fontes)

Quer que o agente responda com base num material seu? Comece simples: um dicionário de trechos. Vetores só se precisar.

from portal.base import AgentResult
from portal import llm

BASE = {                                        # sua "base de conhecimento"
  "devolução": "Trocas em até 7 dias com nota fiscal (art. 49 CDC).",
  "frete":     "Frete grátis acima de R$199 para todo o Brasil.",
}

class FAQAgent:
    slug = "faq-loja"; name = "FAQ da Loja"; emoji = "📚"
    description = "Responde dúvidas citando a política oficial."

    def run(self, message, history):
        # recuperação ingênua: acha os trechos cuja chave aparece na pergunta
        achados = [v for k, v in BASE.items() if k in message.lower()]
        contexto = "\n".join(achados) or "(nenhum trecho relevante)"
        resp = llm.chat([
            {"role": "system", "content": "Responda SÓ com base no contexto. "
             "Se não houver, diga que não sabe."},
            {"role": "user", "content": f"Contexto:\n{contexto}\n\nPergunta: {message}"},
        ], max_tokens=150)
        return AgentResult(answer=resp, citations=achados)   # 👈 fontes na UI

AGENT = FAQAgent()

🤝 Regras de convivência (evita 90% dos problemas)

📁 Edite só agents/<seu-slug>.py. Nunca mexa em portal/.
🏷️ Slug único, minúsculo, sem espaço. Combine com a turma para não repetir.
🌐 Nada de rede no import. Chamadas só dentro de run() (senão trava o portal).
🔑 Sem segredos no código. Token vem do ambiente (HF_TOKEN), nunca hardcoded.
⏱️ Seja rápido. max_tokens baixo, uma chamada só quando possível.
🧪 Sempre rode o preflight antes de commitar.
