03 / 16
Casos
Três testes essenciais

Não tente prever tudo. Comece com três situações diferentes.

1 · Normal Dados completos e pedido dentro do tema Deve criar o plano
2 · Difícil Muitas matérias e pouco tempo disponível Deve priorizar
3 · Inválido Falta a data, o tempo ou o pedido foge do tema Deve pedir dados ou recusar
Mão na massa

Escreva uma pergunta para cada linha.

Se dois testes forem quase iguais, torne um deles mais desafiador.

08 / 16
Guardrails
Limites que ajudam

Um bom agente também sabe quando parar.

1

Fora do tema

“Posso ajudar a organizar estudos, mas não consigo orientar sobre investimentos.”

2

Falta informação

“Quanto tempo você tem disponível hoje?”

3

Pedido adequado

Responde normalmente, sem adicionar avisos desnecessários.

Limite não é “dizer não” para tudo. É explicar até onde o agente é confiável e indicar o próximo passo seguro.

Comparação
Três modos, três papéis

Você não perde o trabalho quando a API acaba.

ModoQuando usarVantagemAtenção
SimuladorConstruir, praticar e testar a estruturaSem modelo, API, token ou internetNão entende o prompt nem mede qualidade
API + QwenValidar poucas hipóteses importantesResposta de IA real via Hugging FaceTem limite, rede e variação
CacheRever uma resposta já obtidaEconomiza chamadas e permite compararNão é uma nova execução
Se a API falhar

Volte ao simulador, registre a limitação e continue.

O objetivo da aula é aprender o método, não depender de uma credencial.
